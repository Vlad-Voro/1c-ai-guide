# Архитектура Event-Driven интеграции 1С и LLM

## 1. Схема контура обработки данных

```
[Почта / ЭДО Диадок / СБИС]
           │
           ▼
[Микросервис предобработки (OCR + Whisper)]
           │
           ▼ (Нормализованный JSON)
[LLM Инференс (Yandex Cloud / On-Premise Llama)]
           │
           ▼ (Валидированный документ)
[1C OData REST Bridge / HTTP-сервис 1С]
           │
           ▼
[Документ «Поступление товаров» в 1C:ERP]
```

## 2. Обеспечение требований безопасности

- **Только HTTPS / TLS 1.3** между всеми внешними шлюзами.
- **RLS-авторизация в 1С**: сервисный пользователь бота имеет доступ строго к ограниченному списку документов.
- Подробнее об аудите безопасности читайте в базе знаний [ai-avtopilot.ru/faq/](https://ai-avtopilot.ru/faq/).
